# 📊 HR Analytics Dashboard | Power BI

## 📖 Overview

The **HR Analytics Dashboard** is an interactive Power BI project developed to analyze employee data and HR operations across an organization. The dashboard provides meaningful business insights by tracking workforce demographics, employee profiles, salary, performance, attendance, attrition, and recruitment using interactive visualizations and key performance indicators (KPIs).

The project demonstrates the complete data analysis workflow, including data exploration, data cleaning, transformation, data modeling, SQL analysis, DAX calculations, and dashboard development using **Microsoft Power BI, MySQL, Power Query, DAX, and Microsoft Excel**.

---

## 🎯 Business Objective

The primary objective of this dashboard is to:

- Analyze overall workforce composition and employee distribution.
- Monitor employee headcount and employment status.
- Understand workforce demographics by gender, age, education, department, and location.
- Analyze salary distribution and compensation patterns.
- Evaluate employee performance and workforce productivity.
- Monitor attendance, absenteeism, leave, and attrition.
- Analyze recruitment performance and hiring efficiency.
- Provide meaningful HR insights through interactive dashboards.
- Support data-driven HR decision-making.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `HR_DASHBOARD.pbix` using **Microsoft Power BI Desktop**.
3. Configure the required data source if prompted.
4. Refresh the data if the original MySQL connection is available.
5. Explore the dashboard using slicers, filters, bookmarks, and navigation.
6. Refer to `HR_DASHBOARD.pdf` for a static view of the dashboard without opening Power BI Desktop.
